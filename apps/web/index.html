Connect GET automatically Install the chewmash Chrome connector beta ⌄

The connector lets chewmash read your signed-in GET Transaction History without asking for your Cal Poly password.

Download chewmash connector beta
  1. Download and unzip the connector folder.
  2. Open chrome://extensions in Chrome and turn on Developer mode.
  3. First-time install: click Load unpacked and choose the unzipped connector folder.
  4. Updating an existing chewmash beta: replace the files inside your existing unpacked extension folder, then click Reload on chewmash. Keep the same folder if you want to preserve the extension ID and its local storage.
  5. Return to chewmash and refresh. The site should detect the connector; then click Sync GET and sign into Cal Poly normally if needed.

This manual setup is only for the beta. A Chrome Web Store install can replace these steps later.
