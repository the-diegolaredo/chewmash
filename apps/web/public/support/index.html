ChewMash technical support

If ChewMash is not syncing or displaying your Dining Dollars data correctly, these steps solve the most common issues.

GET sync

Sign in to GET normally, complete Cal Poly and Duo authentication, then find and select View All Transaction History. ChewMash can only finish the sync after the full transaction-history page is available.

Web app

Make sure the ChewMash connector is installed when using connector-based GET sync. You can also refresh the page, reconnect GET, or restore a previously exported ChewMash backup.

iPhone app

Try Sync GET again from ChewMash. If the app still cannot update, close and reopen ChewMash and repeat the GET sync. Your Cal Poly sign-in remains handled by the Cal Poly/GET sign-in pages.

Report a technical issue

ChewMash is an independent project. Technical issues can be reported through the ChewMash source repository. Do not include passwords, student IDs, card numbers, transaction exports, or screenshots containing private account information in a public report.
